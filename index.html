Este site simula uma interface de terminal.

Use apenas o teclado para navegar.

`Tab` troca entre menu e conteúdo principal.

`h` e `k` vão para o item anterior.

`j` e `l` vão para o próximo item.

No portfólio, `Enter` abre links de projeto em nova aba.

Use `j` ou `l` para ir até o botão abaixo.

visitor@portfolio:~$ currículo-online
Sobre mim Formação Portfólio Contato

[session:portfolio] [file:about.txt] [mode:keyboard]

tab trocar_região

h/k item_anterior

j/l próximo_item
